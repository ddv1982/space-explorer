# Release 1.19.0: Living worlds and cinematic ships

Every campaign level now has its own animated procedural environment. Aurora keeps the flowing light and edge planet from the approved preview; the remaining worlds add blue caustics, ember fronts, mechanical rings, crystals, wreckage, cathedral arches, an eclipse corona, hive membranes, and Eventide's orbital well.

## Cinematic ships

- New authored hulls for the player, Scout, Fighter, Bomber, and Pyre Herald retain detailed 4× source pixels at their existing gameplay sizes.
- Movement, collision bodies, damage, encounter schedules, telegraphs, and laser hazards remain unchanged.
- Missing or invalid hull images show a retry action before gameplay starts.

## Procedural environments

- Generated stars and landmarks stay sharp while atmosphere shading runs in a bounded texture.
- Low quality keeps a static atmosphere. Reduced motion freezes the environment. Auto reduces optional background refresh under sustained pressure.
- Background resources are released on scene transitions, and static backgrounds refill after graphics-context restoration.
- The center flight lane stays dark so ships and attacks remain readable.

## Menu and maintenance

- Returning from a development preview stays on the main menu. Level-jump URL shortcuts remain absent from production builds.
- Editable ship sources and their prompts are committed alongside the export script. Runtime hull downloads total about 60 KB.
- Removed duplicate pilot recording tooling, retired rollout instructions, and stale raster-background documentation. Generated evidence remains local.

## Validation

The release preserves the existing bundle and gameplay performance limits. Automated checks cover both TypeScript compilers, formatting, lint, unit tests, level data, unused code, architecture, dependency audit, build output, and browser behavior. Browser tests exercise desktop and portrait backgrounds, loading and recovery, menu navigation, and repeated campaign transitions.

Physical-device frame rate and thermal behavior still need device qualification. Software-renderer timings do not establish phone or laptop GPU performance.
