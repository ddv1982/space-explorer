# Release 1.9.0 - Chart the Engine-Room Constellations

The flight deck has crossed enough strange skies that its machinery deserves a map of its own. This release opens the sealed bulkheads, separates the instruments that steer encounters and damage, and posts sentries along the dependency lanes so future expeditions cannot quietly knot the ship's wiring again.

## Constellations behind the command deck

- Breaks the gameplay-event dependency cycle by moving the shared scene signal contract into a neutral module.
- Splits enemy selection, spawn dispatch, hazard cadence, and delayed wormhole packs out of `WaveManager` into focused collaborators.
- Moves boss Guard Break calculations into a deterministic controller with direct regression coverage.
- Separates player-damage routing and teardown-safe hazard cleanup from collision orchestration.

## Sentries at every bulkhead

- Adds an architecture gate that maps internal imports and detects source dependency cycles.
- Tracks intentional composition and procedural-rendering hotspots with ratcheted budgets so their complexity cannot silently grow.
- Runs the architecture gate in GitHub Actions alongside the existing static, unit, browser, and bundle lanes.
- Documents scene ownership, system boundaries, shared flow contracts, and the rules for future extractions.

## A stricter flight academy

- Enables strict TypeScript checking across the test project and repairs its Phaser fixtures and mocks accordingly.
- Adds focused coverage for enemy spawn weighting, boss guard state, and player-damage routing.
- Preserves encounter pacing, boss behavior, collision outcomes, visuals, and player controls while reducing coupling beneath them.

## Flight certification

- Passes TypeScript 7, TypeScript 6 compatibility, ESLint, Knip, level validation, the complete isolated unit suite, and production bundle gates.
- Passes desktop and mobile browser smoke coverage plus serialized performance evidence.
- Leaves the optimized projectile trail cadence intact, with materially fewer trail events per shot than the legacy cadence in both measured profiles.
