# Release 1.8.0 - Relight the Neon Command Deck

The same campaign still flies, but the stations shine like a later age of the same war. Command-deck chrome, hotter baked silhouettes, and louder edge skies raise the spectacle without rewriting the authored pressure, telegraph clocks, or one-hit shield contract.

## A later age of the same war

- Intensifies the existing neon-vector language instead of pivoting to painterly ships, photoreal skies, or a new quality axis.
- Locks the remake as presentation-only in `CONTEXT.md`, `docs/art-direction.md`, and ADR 0002.
- Extends the existing Low / Standard / High visual profile with remake FX budgets for UI glow, motif density, particle burst scale, and menu atmosphere.
- Keeps formations, spawn schedules, movement, projectile speed, telegraph windows, hazard geometry, boss phase thresholds, Arcade body sizes, and difficulty-as-forgiveness frozen.

## Command-deck stations

- Rebuilds shared frames, titles, buttons, sliders, and prompts as command-deck chrome with quality-scaled baked glow and reduced-motion-safe prompts.
- Remakes the main menu as a cinematic command deck with mission-card save slots while NEW RUN, load, delete, difficulty, quality, and music contracts stay reachable.
- Matches pause, game over, victory, and planet-intermission chrome to that language; planet-arrival portraits remain the only approved rasters.
- Gives the HUD top bar and mobile pause button the same instrument chrome without changing HULL, RES, or FLIGHT VECTOR labels.

## Hotter hulls, louder skies

- Bakes richer neon silhouettes for ships, pickups, and asteroids, plus a render-only boss corona, without changing texture keys or logical sizes.
- Scales explosion, trail, hit, and warp spectacle with the particle-burst budget while leaving emitter quantities and pause-safe beam clocks untouched.
- Thickens edge motifs by quality tier while the center 45–55% corridor stays darker so Lane-Reading survives the louder look.
- Removes per-object Glow from pickups so only the player and telegraphs keep runtime glow filters.

## Quality corridor

- Adds corridor visual evidence at `984x768` desktop and `390x844` phone portrait, plus command-deck screenshots for menu, pause, game over, and victory.
- Passes TypeScript 7 and TypeScript 6 compatibility checks, lint, the complete isolated unit suite, level validation, Knip, production build, bundle budgets, desktop/mobile functional and visual browser gates, and isolated performance evidence.
