# Release 1.10.0 - Teach the Starship to Breathe

The command deck now listens to the rhythm of every delivered frame. When the sky grows crowded and the engines begin to strain, the ship sheds only ornamental weight—then restores its full radiance carefully once the flight lanes settle. The guns, hazards, physics, and campaign clocks never yield.

## An automatic flight engineer

- Adds an opt-in `AUTO` visual-quality tier that launches with the complete High presentation.
- Samples sustained frame delivery in stable windows instead of reacting to isolated pauses, tab restoration, or debugger stalls.
- Progressively reduces particle quantities, projectile-trail frequency, optional glow, secondary shockwaves, and the third background plane as pressure rises.
- Requires several healthy windows before restoring a single tier of effects, preventing distracting quality oscillation.

## Immutable combat instruments

- Keeps simulation delta, physics, damage, player firing cadence, enemy behavior, encounter timing, and input independent from visual adaptation.
- Applies existing quality particle budgets to explicit Phaser bursts as well as emitter defaults.
- Uses backing-canvas size and reduced-motion preference for initial guidance without device-model or user-agent detection.
- Leaves manual Low, Standard, and High settings fixed and unchanged.

## New gauges on the bridge

- Extends browser evidence with canvas backing and CSS dimensions, device-pixel ratio, effective backing scale, and the active runtime-pressure budget.
- Confirms the renderer already operates near one backing pixel per CSS pixel, avoiding a second resolution system that could disturb scene geometry or input.
- Adds deterministic coverage for pressure escalation, recovery hysteresis, invalid-frame rejection, subscriptions, and environment priming.

## Leaner production cargo

- Removes the development browser harness from production builds while retaining it for local and CI Playwright missions.
- Separately guards application JavaScript and the Phaser engine chunk so future growth points to the responsible cargo hold.
- Reduces production JavaScript from 1,792.25 kB to 1,778.45 kB while adding the adaptive runtime.

## Flight certification

- Passes TypeScript 7, TypeScript 6 compatibility, ESLint, Knip, level validation, dependency-cycle checks, production build, and bundle gates.
- Passes the complete isolated unit suite, desktop/mobile browser smoke missions, and serialized performance evidence.
