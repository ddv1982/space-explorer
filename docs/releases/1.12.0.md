# Release 1.12.0 - Open the Cartographer's Ledger

The shipwright's atlas now opens into a ledger any watch officer can follow. Diagnostic instruments occupy named cabinets, the combat deck declares every system it receives, and encounter law is charted apart from the machinery that carries it into flight.

## Instruments in named cabinets

- Divides the browser harness into focused snapshot, contract, navigation, gameplay-probe, runtime-control, and visual-pilot modules.
- Reduces the top-level diagnostics facade from 944 to 388 lines while preserving its browser contract and development-only loading boundary.
- Keeps visual and performance evidence directly comparable after the extraction.

## Every berth declared

- Replaces implicit `GameScene` runtime assignment with an explicit installation manifest for every gameplay and presentation dependency.
- Separates boss targeting, escort deployment, and projectile access behind a focused attack runtime.
- Keeps `GameScene` and `Boss` recognizable as lifecycle owners rather than scattering their commands across generic abstractions.

## Encounter law on its own charts

- Gives authored section events a coordinator with clear once-only ownership.
- Extracts encounter pressure and cadence policy, responsive wave geometry, and hazard dispatch from `WaveManager`.
- Preserves authored event order, random encounter timing, hazard behavior, and asteroid scheduling behind the existing facade.

## A common language for the command glass

- Introduces shared responsive viewport vocabulary while retaining scene-specific layout identity.
- Replaces dense pause-slot decisions with named policies and centralizes intermission mode classification.
- Groups enemy, projectile, and world constants by domain; separates player-state and music-arrangement contracts into focused modules.

## Charts that tighten behind the crew

- Lowers architecture concentration budgets to the new module sizes and records narrow reasons for deliberately concentrated pure policies.
- Documents coherent large-test narratives with near-current budgets so unrelated behavior cannot accumulate silently.
- Records the completed phased plan and updates architecture guidance for diagnostics, layout policy, public surfaces, and test ownership.

## Flight certification

- Passes formatting, TypeScript native and TypeScript 6 compatibility, ESLint, Knip, level validation, architecture and cycle checks, the complete unit suite, production build, and bundle guardrails.
- Passes 34 desktop/mobile functional and visual browser checks with one intentional project skip.
