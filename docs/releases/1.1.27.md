# Release 1.1.27 - stage premium campaign skies on demand

Move the premium background pack onto a campaign-window load path while hardening delayed visual feedback and preserving every level's authored presentation.

## Highlights

- Loads only the Level 1-2 premium background window during startup instead of decoding all ten campaign skies.
- Warms later background windows during intermission and ensures checkpoint or Menu destinations are ready before Game starts.
- Releases premium textures outside the active level window only after the incoming Game parallax has claimed its layers.
- Prevents stale player tint and camera color-pulse callbacks from mutating a later visual lifecycle.
- Centralizes repeated collision-target and best-effort side-effect behavior without changing combat outcomes.
- Moves bomber, gunship, and swarm tuning values into the shared constants surface without retuning them.
- Adds focused transition, loader failure, texture release, callback lifecycle, and shared Phaser-mock regression coverage.

## Lore

Constraint: Preserve authored campaign art, scene ownership, procedural fallback, and combat tuning while reducing startup decode pressure and runtime texture residency.
Rejected: Preload all ten premium skies | It keeps transitions simple but pays the full campaign download and decode cost before the first sortie.
Rejected: Release old textures inside transition callers | Outgoing Menu or Game scenes may still own those textures, so reclamation belongs after the incoming Game parallax claims its layers.
Rejected: Introduce a general asynchronous scene-transition framework | Three explicit transition seams and one focused loader helper solve the current ownership problem without widening scene orchestration.
Confidence: high
Scope-risk: medium
Directive: Keep the next campaign sky warm, reclaim the route behind the player, and never let delayed feedback cross a ship or camera lifecycle.
Tested: `bun run build`; `bun run typecheck`; `bun run lint`; `bun run test`; `bun run levels:validate`; `bun run knip`; `bun run bundle:check`; `git diff --check`.
Not-tested: Manual browser/mobile smoke was not run in this terminal session; startup network behavior and transition presentation should still be observed on a throttled device.
