# Release 1.11.0 - Chart the Shipwright's Atlas

The command deck now carries an atlas of its own machinery. Runtime systems report where they belong instead of passing through mirrored hatches, combat rules can be read away from the engine glow, and new structural sentries mark the corridors where complexity is gathering.

## An explicit engine-room manifest

- Replaces the broad `GameScene` getter/setter bootstrap bridge with a focused host contract and a concrete returned runtime.
- Makes startup order visible from level initialization through world, input, gameplay, presentation, pause wiring, and lifecycle registration.
- Reduces `GameScene` from 480 to 429 lines and bootstrap orchestration from 237 to 162 lines.

## Rules outside the machinery

- Extracts boss phase-two decisions into a Phaser-independent resolver with direct state-transition evidence.
- Gives authored wave and recovery events a dedicated once-only tracker.
- Separates collision registration from collision outcomes, reducing `CollisionManager` from 491 to 376 lines.
- Introduces a centralized typed escape hatch for legacy Phaser entity tests while pure domain rules continue replacing private-state setup.

## Navigational instruments

- Adds a documentation map, runtime map, common change paths, and a concise vocabulary for project-specific concepts.
- Extends architecture reporting with long-function, complexity, public-surface, and concentrated-test warnings alongside cycle and module checks.
- Documents maintainability conventions for construction, resolution, listener registration, teardown, runtime ownership, and justified extraction.

## One hand across every chart

- Establishes Prettier as the deterministic TypeScript and project-configuration formatter.
- Normalizes the existing codebase once and adds formatting verification to GitHub quality gates.
- Keeps structural warnings advisory so intentional façades and procedural recipe catalogs remain visible without encouraging mechanical file splitting.

## Flight certification

- Passes formatting, TypeScript 7, TypeScript 6 compatibility, ESLint, Knip, level validation, architecture and cycle checks, the complete unit suite, production build, bundle limits, and whitespace validation.
- Passes desktop and mobile browser smoke coverage across gameplay startup, scene routing, pause and resize recovery, quality controls, intermission upgrades, and teardown.
- Reduces application JavaScript by roughly 2.6 kB raw while improving its ownership boundaries.
