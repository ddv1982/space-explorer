# Release 1.13.0 - Bind the Sentry's Concordance

The Cartographer's Ledger now answers to a stricter watch. Every unusual chart bears its purpose, proof, and permitted span; every unknown signal stops the certification bell until the crew understands it.

## Known constellations named

- Classifies retained architecture into authored data, composition roots, drawing recipes, presentation builders, pure layouts, runtime coordinators, and coherent test narratives.
- Separates reviewed concentration from actionable warnings instead of presenting both as the same background noise.
- Keeps scores, visual recipes, and responsive geometry intact when their ordering and shared coordinate systems are the clearest expression of the domain.

## Proof beside every chart

- Records a concrete rationale and regression-evidence trail for every retained source policy.
- Holds every policy beneath a near-current line/import or line/complexity ceiling.
- Keeps the full retained inventory visible and grouped by category during every architecture check.

## The sentry closes the gate

- Fails certification on any unexplained concentration, complex function, broad public surface, or oversized test narrative.
- Rejects missing targets, stale entries, exceeded function budgets, exceeded module budgets, and dependency cycles.
- Adds a dedicated regression test proving the report remains free of actionable warnings and contains every required policy family.

## Charts for the next watch

- Updates the structural guidelines with the new failure semantics and evidence requirements.
- Records why semantic cohesion won over arbitrary file slicing for the current residual hotspots.
- Preserves downward pressure: every future extraction must lower or remove its former allowance.

## Flight certification

- Passes formatting, TypeScript native and TypeScript 6 compatibility, ESLint, Knip, level validation, architecture and cycle checks, the complete isolated unit suite, production build, and bundle guardrails.
