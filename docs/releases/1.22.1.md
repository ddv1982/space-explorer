# Release 1.22.1: Quicker flight response

Playtest feedback on 1.22.0: the floaty handling is right, but the ship takes too long to respond to the movement controls.

## Flying

- Thrust is doubled to 1600 px/s². The ship reaches full speed in about half a second instead of a second, and a full reversal takes under a second instead of about two.
- The 800 px/s cap and the 400 px/s² drag stay, so the ship still slides roughly 800 px after you let go.
- Touch drag uses the same thrust, so the ship catches up with your finger sooner and still eases onto it without overshooting.

## Verification

Both TypeScript compilers, lint, formatting, unit tests, level validation, unused-code and architecture checks, build and bundle limits pass locally. The simulated pilot checks for flare and lattice gaps pass with the new thrust, as do the desktop and touch browser suites.
