# Release 1.7.2 - Jettison the Silent Holds

The hull still answers every live command, but unused cargo no longer rides the hold. Dead wiring, silent sparks, and one-job bridges leave the ship so the flight deck carries only the instruments that still fire.

## Unused cargo leaves the hold

- Removes public methods and helpers that no production path called: encounter progress, asteroid-group access, pointer and joystick-pointer probes, warp cancel/is-running, enemy-bullet fire, and test-only shield persist.
- Leaves campaign authoring, formations, spawn schedules, telegraph windows, and encounter grammar untouched.
- Keeps reserved music catalogs, VAT/theme prose, and the GameScene bootstrap stack for later authoring rather than deleting a composer palette.

## Silent guns and unused sparks

- Deletes the unused ambient-sparkle and ember particle chain, including textures and emitter setup that never reached the playfield.
- Removes the unused enemy-fire SFX path from the audio deck.
- Strips unread neon, button, slider, menu-layout, and intermission fields that never shaped a rendered station.

## A thinner command stack

- Inlines the GameScene flow-context and helper-wing forwarding modules so persist, scene start, and best-effort cleanup call their owning helpers directly.
- Drops the forwarding-only tests and folds `runBestEffort` coverage onto the owning utility.
- Preserves fatal-hit flash, helper-wing persist, and the last-life death precedence over a queued level complete.

## Quality corridor

- Passes TypeScript 7 typecheck, lint, Knip, and the complete isolated unit suite.
- Confirms no remaining callers of the removed APIs and no campaign-definition edits.
