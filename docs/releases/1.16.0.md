# Release 1.16.0 - Let Every Signal Reach the Deck

The command deck already painted the right controls, but not every pilot could reach the same state through them. Saves could collide across tabs, late-spawned enemies inherited an old clock, and the performance contract lacked a release-blocking signal. This cut carries each command through its full circuit while preserving encounter grammar, pause behavior, and the neon-vector presentation.

## Every hand reaches the same controls

- Gives menu, pause, intermission, victory, and game-over workflows complete named-action coverage without painting a second interface over the canvas.
- Keeps keyboard and assistive-technology focus stable while semantic actions update or reorder.
- Mirrors difficulty, visual quality, music tuning, disabled actions, and status announcements between painted and semantic controls.
- Restores canvas accessibility ownership cleanly when scenes replace or remove their action layers.

## Sound returns on the trusted beat

- Resumes browser-policy-suspended audio directly from the first trusted menu or settings action.
- Deduplicates overlapping resume attempts and absorbs browser rejections so a later gesture can retry.
- Preserves gameplay and visibility pause reasons; an action never resumes audio the application intentionally suspended.

## Clocks and saves keep local truth

- Starts enemy firing cycles from accumulated gameplay delta after each spawn instead of inheriting scene uptime.
- Stores each checkpoint under an atomic v2 per-slot key so concurrent tabs cannot overwrite unrelated slots.
- Uses per-slot tombstones for deletion and continues reading valid shipped v1 envelopes during migration.
- Keeps valid records visible when one storage representation is malformed or a write is rejected.

## A measured gate to orbit

- Measures exactly ten gameplay update/render samples after two warm-up frames across five fresh normal replicates.
- Requires every normal update p95 to remain at or below the characterized 5 ms Ubuntu ceiling in the dedicated desktop gate.
- Injects 6 ms of harness-only update work into five synthetic replicates and requires the same assertion to reject all five with an exact marker.
- Runs normal and synthetic evidence independently on GitHub-hosted `ubuntu-24.04` and retains both artifact sets even when the normal gate fails.
- Moves performance coordination out of the browser-harness composition root while preserving its public development API and production exclusion.

## Flight certification

- Passes formatting, TypeScript native and TypeScript 6 compatibility, ESLint, Knip, level validation, architecture and cycle checks, the complete isolated unit suite, production build, and bundle guardrails.
- Passes 41 applicable desktop/mobile functional and visual browser checks with one intentional project skip.
- Passes the local SwiftShader normal gate at a maximum update p95 of 0.5 ms and rejects all five synthetic replicates at 6.2-6.4 ms.
- Calibrates the 5 ms ceiling from two source-bound GitHub-hosted `ubuntu-24.04` runs while retaining local Darwin measurements only as reference.
