# Release 1.14.0 - Set the Command Deck in True Orbit

The Command Deck no longer crowds its own call sign. Its crown, instruments, and launch berths now hold deliberate orbits: clear at a wide bridge, orderly on a tablet station, and intact in the narrow glass of a field handset.

## The call sign clears the crown

- Rebuilds `COMMAND DECK`, `SPACE EXPLORER`, and the mission prompt as one measured title lockup.
- Reserves the display font's true rendered line box so glow and glyphs cannot pass through neighboring text.
- Reduces the desktop title ceiling, clamps its signal wings to available space, and stows the eyebrow on short landscape screens.

## Every station finds its orbit

- Separates the deck into title, mission settings, tuning controls, run selection, and status bands.
- Uses spare desktop height to lower the launch berths and relieve the crowded upper console.
- Aligns difficulty, quality, tuning sliders, and save cards on a shared visual grid with clearer transitions between duties.

## Five bridges, one flight plan

- Introduces named desktop, tablet, phone-portrait, phone-landscape, and ultra-compact profiles.
- Stacks portrait tuning controls above a two-column run grid while short portrait stations use a compact two-column tuning deck.
- Keeps short landscape controls in two columns with a compact four-card launch row.
- Preserves all required settings and run actions from `1366x768` down through the supported `480x320` landscape and `360x600` portrait stations.

## The lens measures what the crew sees

- Extends development snapshots with rendered text width and height.
- Replaces guessed anchor rectangles with semantic band ordering and actual glyph-box separation checks.
- Captures responsive menu evidence at seven representative viewports and retains the existing interaction, visual-cost, and frame-pacing sentries.

## Flight certification

- Passes formatting, TypeScript native and TypeScript 6 compatibility, ESLint, Knip, level validation, architecture and cycle checks, the complete isolated unit suite, production build, and bundle guardrails.
- Passes 34 functional and visual browser checks with one intentional project skip.
- Passes all four applicable desktop/mobile performance scenarios with two intentional mobile project skips.
