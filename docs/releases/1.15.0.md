# Release 1.15.0 - When the Deck Holds, the Sector Holds

Pause used to let the sector keep spending the crew's time. Chains died in the overlay. Helper wings came back early. Picket mounts kept their cadence. This cut gives combat one clock that only moves while the fight is live, and it makes the deck's other promises match that hold: a delete that waits for a second tap, hands that do not argue, hits a thumb can find, and a production gate that will not ship a red build.

## The fight waits in the hold

- Counts combat time on one `GameplayClock` that advances only on unpaused frames.
- Leaves Phaser's scene clock running for HUD chrome, tweens, and flashes.
- Keeps score chains, gun cooldown, helper respawn, and picket fire where they were when the overlay opened.
- Lets the `PICKET ONLINE` banner follow scene time so a slow renderer still sees it about three seconds after the mounts deploy.

## Hands that do not argue

- Ignores held Enter and Space on the intermission shop so one key cannot buy a stack.
- Hides the virtual joystick when a hardware key arrives and brings it back on the next pointer.
- Floors menu, pause, and shop hit areas at 44 CSS pixels. The neon chrome can stay smaller. The tap cannot.
- Adds a visually hidden named-action layer for the command deck, pause, and intermission. The canvas stays the painted UI.

## A save that tells the truth

- Keeps live shield charges through save and load, capped at eight.
- Floors authored campaign levels so a broken slot cannot jump the map.
- Probes storage with a write before claiming a save succeeded.
- Arms delete on the first DEL tap and commits only on the second.

## One gate to orbit

- Deploys from the quality workflow only after static and browser jobs pass.
- Pins the Vercel CLI, scopes tokens to deploy steps, and uses the production environment.
- Sends CSP and related headers with the shipped build.
- Fails certification when an architecture budget sits more than 80 lines above the measured file.

## Flight certification

- Passes formatting, TypeScript native and TypeScript 6 compatibility, ESLint, Knip, level validation, architecture and cycle checks, the complete isolated unit suite, `bun audit --audit-level=high`, production build, and bundle guardrails.
- Passes 36 functional and visual browser checks with one intentional project skip.
- Passes three applicable desktop/mobile performance scenarios with three intentional project skips.
