# Runtime artwork provenance

Created with the built-in image model on 2026-09-05 using the selected Cinematic Frontier board as a style reference. All hulls underwent image-model background extraction until their saved files had real alpha. Rejected opaque checkerboard variants were not exported. cwebp performs runtime resizing and compression; no image-removal script was used.

Match the ceramic/titanium cinematic material style of the reference, but output ONLY the specified spacecraft. Strict straight upward orientation. Vertical canvas close to 36:44 aspect ratio.

## Extraction and boss revision

Extraction prompt: Remove the checkerboard background completely. Return the identical isolated spacecraft with a genuinely transparent alpha background. Preserve the ship exactly, its colors, shape, downward orientation and position. Background extraction only. No checkerboard pixels, no white, no black background.

Final scout extraction prompt: Make the background transparent. Cut out the spacecraft as a PNG with alpha channel. Remove ALL checkerboard squares. Keep spacecraft unchanged.

The final boss was revised from the transparent bomber reference with this prompt: Edit this transparent game sprite into a wide boss battleship, Pyre Herald. Make its hull wider than tall (88:56), use burnt copper and charcoal graphite armor instead of yellow. Two broad armored wings with heavy guns facing down, recessed small red central core, three engines at top. Orthographic straight top down. Keep a real transparent alpha background exactly like the input. No checkerboard and no other background. Keep a margin of transparent pixels all around.

Final boss extraction prompt: Remove background

The committed source names match `bun run art:export`. Runtime hull dimensions come from `src/config/cinematicAssets.ts`. Readiness rejects a dimension mismatch before gameplay construction. Browser tests check both transparent and near-opaque pixel coverage; the image model's hull alpha peaks at 254, not 255.
